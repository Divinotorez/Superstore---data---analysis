# Superstore Data Analysis

Analysis of sales and profitability using Microsoft Excel.

## Project Overview

This project focuses on the analysis of the Superstore dataset using Excel.

The objective is to transform raw data into meaningful insights through data preparation, analysis and reporting.

## Workflow

- Raw data
- Data cleaning and preparation
- Data analysis
- KPI analysis
- Reporting and visualization
- Interactive navigation menu

## Key Areas Analyzed

- Sales performance
- Profitability
- Customer segments
- Product categories
- Geographic performance
- Shipping modes and delivery times
- Discounts
- Sales and profit trends

## Tools

- Microsoft Excel
- Excel formulas
- Pivot Tables
- Charts
- Slicers
- Data preparation an formationg
